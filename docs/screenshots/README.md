# Marketplace screenshots

Use these PNGs when editing the [JetBrains Marketplace](https://plugins.jetbrains.com/) listing and in the GitHub README.

| File | Use |
|------|-----|
| `linked-issue-card.png` | Linked issue — Feedback1 card (priority, title, votes, revenue, status) |
| `issues-list-columns.png` | Issues list with Votes / Revenue columns |
| `app-settings.png` | App global settings (API key, Show revenue) — replace with a real YouTrack capture when available |
| `unlinked-or-error.png` | Empty / error card — replace with a true unlinked state capture if you prefer |

Recommended width for Marketplace: about **1280px**. Re-capture after major UI changes.
